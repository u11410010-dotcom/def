## 🎯 教學重點（逐音流程）

1. **① 開字母**：例如 D → `D, dump truck` → 唸「杜」
2. **② 真正聲音**：`/d/` → `duh`
3. **③ 慢慢唸**：`dump truck`（慢速 0.45×）
4. **③ 正常唸**：`dump truck`（正常）
